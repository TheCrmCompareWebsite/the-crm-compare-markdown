# The CRM Compare Website: reports and comparisons

Independent scores for real estate CRMs, as Markdown. The same reports and comparisons are published as web pages at https://thecrmcomparewebsite.github.io/the-crm-compare-website/

Every file here is generated by the CRM Compare build pipeline from each CRM's research data and text, and replaced on each rebuild, so edit the pipeline or the CRM's files, not these.

- `reviews/`: one report per CRM (26)
- `compare/`: head-to-head comparisons (71)

Each file starts with YAML front matter (score, rank, dates, its web page) for other tools to read.
